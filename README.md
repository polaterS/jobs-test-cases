# Cityberry® - Jobs Test Cases 🚀

Welcome to the **Cityberry Travel Technologies & Services** official test case repository!  
This repository contains coding challenges for different developer positions.  

## 📌 **How It Works**
1. Find the relevant test case for your application under the **branches** section.  
2. Follow the instructions in the README file inside the branch.  
3. Complete the test and submit your solution as a **Pull Request (PR)**.

## 🛠 **General Guidelines**
- Fork this repository and switch to the relevant test case branch.  
- Read the instructions carefully and complete the given tasks.  
- Submit a **Pull Request (PR)** with your solution within the deadline.  
- Make sure to include your **GitHub profile/portfolio** in your submission.
